HPC Support Handbook

Role: Program Coordinator / Research Computing Support

Institution: Claremont Colleges – Quantitative & Computing Lab (QCL)

Designed and maintained a comprehensive High-Performance Computing (HPC) support handbook to guide students, faculty, and researchers in accessing and using campus research computing infrastructure.

The handbook translates complex computational systems into accessible, structured documentation, supporting onboarding, troubleshooting, and research workflows across disciplines.

Key Contributions:

  • Structured end-to-end HPC onboarding documentation
  • Designed instructional workflows for research computing users
  • Improved accessibility of technical systems for non-expert users
  • Maintained GitHub-based documentation workflow (Bookdown / Markdown)
  • Supported reproducible research computing practices

Skills Demonstrated: Technical documentation, research computing support, instructional design, GitHub workflows, systems communication

Repository: Claremont Colleges QCL GitHub Organization
